# 📊 Sales Performance Dashboard

## Syntecxhub Data Analysis Internship Project

This project was completed as part of the **Syntecxhub Data Analysis Internship**.

The project focuses on analyzing a SuperStore sales dataset and developing an interactive **Sales Performance Dashboard** using **Microsoft Power BI**.

---

## 🎯 Project Objective

The objective of this project is to analyze sales performance across different:

- Time periods
- Regions
- Categories
- Sub-categories
- Products
- Customer segments

The dashboard provides interactive KPIs and visualizations to help understand sales, profit, returns, and product performance.

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop**
- **Power Query**
- **DAX**
- **Microsoft Excel / CSV Dataset**
- **GitHub**
